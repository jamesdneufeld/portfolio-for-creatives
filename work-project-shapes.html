Make It Your Own

The shapes are created with SVG paths and used as CSS clip-paths to mask each project image. You can replace the shapes with your own SVG paths, but they need to be normalized to the 0–1 objectBoundingBox coordinate system. Project images, overlay colours, and shapes can all be customized in project-shapes.css .
